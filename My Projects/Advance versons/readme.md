# 🎓1. Student Management System

A beginner-friendly **Student Management System** built in Python using **Object-Oriented Programming (OOP)**. This project allows users to manage student records through a simple menu-driven interface. Student data is stored in a **JSON file**, so records are saved permanently even after the program is closed.

## ✨ Features

* ➕ Add new students
* 📋 Display all student records
* 🔍 Search students by name
* 🏢 Search students by department
* ✏️ Update student marks
* ❌ Delete student records
* 💾 Save data to a JSON file
* 📂 Load data automatically when the program starts
* ✅ Input validation and exception handling

## 🛠️ Technologies Used

* Python
* Object-Oriented Programming (OOP)
* Functions
* Dictionaries & Nested Dictionaries
* Loops & Conditional Statements
* Exception Handling
* JSON
* File Handling

## 🎯 Learning Outcomes

This project helped me understand how to organize data using nested dictionaries, apply OOP concepts, validate user input, handle exceptions, and use JSON for permanent data storage. It also strengthened my problem-solving and Python programming skills by building a complete CRUD (Create, Read, Update, Delete) application.

# 🏦3.  Bank Management System

A console-based **Bank Management System built with Python** using OOP, JSON storage, input validation, exception handling, and transaction management.

## 🚀 Features

* Create multiple bank accounts
* Account number validation
* Login with PIN
* Deposit money
* Withdraw money
* Transfer money between accounts
* Transaction history
* Search accounts
* Delete accounts
* Store data permanently using JSON
* Input validation and error handling

## 🛠️ Concepts Used

* Python Classes & Objects
* Object-Oriented Programming (OOP)
* Dictionaries & Nested Data
* Lists
* Functions
* Loops
* `try-except` Exception Handling
* JSON (`json.load()` / `json.dump()`)
* File Handling
* Input Validation

## 💾 Data Storage

All account information is stored in a **JSON file**, allowing the data to remain available even after the program is closed.

Each account contains information such as:

* Username
* Account Number
* PIN
* Balance
* Transaction History

## 🔄 Transfer System

The transfer feature allows a logged-in user to:

1. Enter the receiver's account number.
2. Validate the receiver.
3. Enter the amount.
4. Check the sender's balance.
5. Deduct money from the sender.
6. Add money to the receiver.
7. Record both transactions.
8. Save the updated data to JSON.

## 🎯 Project Goal

The goal of this project is to practice **Python programming, OOP, nested dictionaries, JSON file handling, validation, and real-world problem-solving** by building a simple banking application.

* Date and time for transactions

* Maximum PIN attempts / account lock
* Improved user dashboard
